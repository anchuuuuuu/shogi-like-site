1. 取得する情報

本アプリは、メールアドレス、パスワード、氏名、住所、電話番号、位置情報、連絡先、写真などを取得しません。アカウントの登録もありません。取得する情報は次のとおりです。

(1) ランキング機能のために運営者のサーバーへ送る情報

  • 端末から作られる識別子（uuid）。氏名などでお客様を特定するものではなく、端末ごとの記録を区別するために使います。
  • ゲームのモード、到達した面、手数、ゲームオーバーまたはクリアの別、やり直し（リトライ）と引き直し（リロール）の回数。ゲームオーバーまたはクリアしたときに送ります。
  • ユーザー名。お客様が名前を変更したときだけ送ります。ユーザー名はランキングに表示され、他のお客様にも見えます。本名や個人を特定できる名前は付けないでください。

(2) 広告の配信のために広告 SDK が取得する情報

本アプリは広告を表示するため、第6項の広告配信事業者の SDK を組み込んでいます。SDK は、広告識別子（iOS の IDFA、Android の広告 ID）、IP アドレス、端末の種類・OS・言語などの端末情報、広告の表示・操作の履歴を取得することがあります。これらは各社が自らの方針に基づいて取得・利用するもので、運営者が受け取るものではありません。各社の取り扱いは、第6項のポリシーでご確認ください。

iOS では、広告識別子を使うために、トラッキングの許可を求める画面（App Tracking Transparency）を表示します。許可しない場合、広告識別子は使われません。許可は、端末の「設定」アプリからいつでも変更できます。

(3) 広告オフの購入にかかる情報

第4項に記載します。

(4) お問い合わせの際にいただく情報

お問い合わせをいただいたときは、お客様のメールアドレスと、お問い合わせの内容、ご案内に必要な端末・OS・購入に関する情報を、メールの範囲でお預かりします。

(5) 端末内にだけ保存する情報

ゲームの進行状況（デッキ、到達した面、設定など）は、お客様の端末内に保存され、運営者のサーバーには送られません。アプリを削除すると失われます。

(6) 公式サイトの閲覧

公式サイトは GitHub Pages で配信しています。閲覧すると、IP アドレスなどのアクセス情報が GitHub に記録されることがあります。また、文字の表示に Google Fonts を読み込むため、閲覧時にお客様の IP アドレスが Google に送られます。運営者は、公式サイトにアクセス解析やクッキーを設置していません。

2. 利用目的

  • ランキングの集計と表示、不正なスコアの検出と防止のため
  • 広告の表示と、その配信・計測のため（広告配信事業者による）
  • 広告オフの購入の確認・復元・返金への対応、および不正の防止のため
  • 不具合の調査・修正と、サービスの運営・改善のため
  • お問い合わせへの対応のため
  • 法令に基づく対応のため

3. 広告に関する設定

iOS では、トラッキングの許可を拒否するか、端末の「設定」でトラッキングを許可しないことで、広告識別子を使った広告の最適化を止められます。Android では、端末の設定にある広告 ID の削除やパーソナライズ広告のオプトアウトで、同様に止められます。この場合も広告は表示されますが、お客様の好みに合わせたものではなくなります。

4. 課金（広告オフ）について

広告オフ（買い切りのアプリ内課金）は、今後のアップデートで追加予定です。以下は、追加後の取り扱いです。

本アプリには、広告オフ（バナー広告の非表示と、リワード広告を見ずに報酬を受け取れる機能）を購入できるアプリ内課金があります。

  • 決済の主体：決済は Apple（App Store）または Google（Google Play）が行います。クレジットカード番号などの決済情報は、運営者は受け取りません。
  • 受け取る情報：購入を確認するため、Apple または Google から受け取る取引情報（取引 ID、商品 ID、購入日時、購入トークン）を、端末の識別子（uuid）に結びつけて運営者のサーバーに保存します。
  • 利用目的：購入の確認、機種変更や再インストール後の購入の復元、返金・取り消しの通知を受けたときの広告オフの解除、不正な購入の防止。
  • 保存先：運営者が利用するサーバー（Amazon Web Services、Supabase）。
  • 保存期間：広告オフの提供と購入の確認のため、本サービスの提供を終了するまで保存し、その後削除します。
  • 返金：返金の可否は Apple・Google の規定によります。返金や取り消しの通知を受けると、広告オフは解除されます。

提供：運営者は、次の場合を除き、お客様の情報を第三者に提供しません。

  • ご本人の同意がある場合
  • 法令に基づく場合
  • 人の生命、身体または財産の保護のために必要があり、ご本人の同意を得ることが困難な場合
  • 国の機関や地方公共団体、またはその委託を受けた者が法令の定める事務を行うことに協力する必要があり、ご本人の同意を得ることで事務の遂行に支障を及ぼすおそれがある場合

なお、広告 SDK が広告配信事業者へ送る情報（第1項(2)）は、運営者がお客様の情報を提供するものではなく、各社が SDK を通じて自ら取得するものです。

委託：サーバーの運用とデータの保存のため、次の事業者のサービスを利用しており、利用目的の範囲で情報の取り扱いを委ねています。

  • Amazon Web Services（プライバシー）
  • Supabase（プライバシー）

共同利用：行いません。
